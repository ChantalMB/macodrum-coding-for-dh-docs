# Boolean Operators

### If expression uses "and"...
| Expression      | Evaluation |
| --------------- | ---------- |
| True and True   | True  |
| True and False  | False |
| False and True  | False |
| False and False | False |

### If expression uses "or"...
| Expression     | Evaluation  |
| -------------- | ----------- |
| True or True   | True  |
| True or False  | True  |
| False or True  | True  |
| False or False | False |
