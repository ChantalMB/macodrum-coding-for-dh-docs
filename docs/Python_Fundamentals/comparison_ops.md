# Comparison Operators

!!! warning

    **Remember:** '=' is the assignment operator, not used for comparison!

| Operator |  Meaning |
| -------- |  ------- |
| ==       |  Equal to  |
| !=       |  Not equal to  |
| <        |  Less than |
| >        |  Greater than  |
| <=       |  Less than or equal to |
| >=       |  Greater than or equal to  |
